## 模块职责速览

| 模块 | 技术/职责 |
|---|---|
| `backend` | Spring Boot + MyBatis Plus，提供认证、基础数据、排课、方案、分析、V5 修复试算等 REST API |
| `frontend` | Vue 3 + Vite + Element Plus，提供管理后台、课表展示、方案分析、智能修复页面 |
| `docs` | V1-V5 需求、设计、接口、数据库、测试验收和审查文档 |
| `scripts` | 自动化脚本，目前包含 API 冒烟测试 |
| `tests` | Playwright E2E/阶段测试 |
| `output` / `test-results` | 浏览器调试、截图、测试运行产物 |

## 后端分层

```text
Controller -> Service -> Mapper -> Entity -> Database
             ├── DTO：请求参数
             ├── VO：响应对象
             ├── common：异常、枚举、统一响应
             ├── auth：登录、JWT、CSRF、限流
             └── resources/db：schema 与阶段 SQL
```

## 前端分层

```text
View -> API Client -> Axios Request -> Backend REST API
      ├── router：路由与页面入口
      ├── stores：登录状态
      ├── layout：后台布局
      ├── components：通用课表/业务组件
      ├── composables：复用逻辑
      └── utils：请求、错误、状态、常量
```

## 版本能力分布

| 版本 | 主要能力 |
|---|---|
| V1 | 基础数据、教学任务、手动排课、冲突检测、课表查询 |
| V2 | 教师禁排、规则配置、自动排课、未排任务、冲突报告、评分报告、Excel 导出 |
| V3 | 学期管理、排课方案、多方案生成、评分明细、方案对比、方案应用、历史回滚、排课日志 |
| V4 | 排课质量分析、风险诊断、图表、局部调整、课程锁定、报告导出、AI 辅助分析 |
| V5 | 智能修复建议、候选位置推荐、试算方案、局部重排、优化前后对比、一致性检查、AI 修复解释 |
