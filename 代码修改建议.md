### A5. JwtService 显式校验密钥长度（对应 2.1）

**文件**：`backend/src/main/java/com/paike/scheduler/auth/JwtService.java:21-32`

```diff
  public JwtService(
      @Value("${app.jwt.secret}") String secret,
      @Value("${app.jwt.expiration-ms}") long expirationMs
  ) {
      if (secret == null || secret.isBlank() || DEFAULT_SECRET.equals(secret)) {
          throw new IllegalStateException(
              "JWT_SECRET 未配置或仍为默认占位值；拒绝启动。请通过环境变量 JWT_SECRET 注入一个长度 >= 32 字节的强密钥。"
          );
      }
+     // jjwt 的 Keys.hmacShaKeyFor 会在 < 256 bit 时抛 WeakKeyException，但报错信息晦涩，
+     // 这里提前做显式长度校验，让运维更容易理解失败原因。
+     int lengthBytes = secret.getBytes(StandardCharsets.UTF_8).length;
+     if (lengthBytes < 32) {
+         throw new IllegalStateException(
+             "JWT_SECRET 长度过短（当前 " + lengthBytes + " 字节，要求 >= 32 字节）。HS256 算法需要至少 256 bit 的密钥。"
+         );
+     }
      this.secretKey = Keys.hmacShaKeyFor(secret.getBytes(StandardCharsets.UTF_8));
      this.expirationMs = expirationMs;
  }
```

```java
import org.springframework.security.config.annotation.web.configurers.AbstractHttpConfigurer;
import org.springframework.security.config.http.SessionCreationPolicy;
import org.springframework.security.crypto.bcrypt.BCryptPasswordEncoder;
import org.springframework.security.web.SecurityFilterChain;
import org.springframework.security.web.header.writers.ReferrerPolicyHeaderWriter;

@Configuration

    }
```

```java
public @interface RequirePermission {

// backend/.../common/aspect/RequirePermissionAspect.java
@Aspect @Component
public class RequirePermissionAspect {
```

```vue
}
</script>
```

### D4. 软删除补齐（对应 3.16）

#### D4.1 优先补齐三张关键业务表

按风险评估，最关键的是：
1. `schedule_locked_item`（锁定课程） → 误删会让锁定状态丢失；
2. `schedule_adjust_log`（调整日志） → 应该永久保留；
3. `schedule_unassigned_task`（未排原因） → 历史追溯依据。

**迁移脚本**（V4__add_soft_delete.sql）：

```sql
-- schedule_locked_item
SET @col_exists := (SELECT COUNT(*) FROM information_schema.COLUMNS
    WHERE TABLE_SCHEMA = DATABASE() AND TABLE_NAME = 'schedule_locked_item' AND COLUMN_NAME = 'deleted');
SET @ddl := IF(@col_exists = 0,
    'ALTER TABLE schedule_locked_item ADD COLUMN deleted TINYINT NOT NULL DEFAULT 0',
    'SELECT 1');
PREPARE stmt FROM @ddl; EXECUTE stmt; DEALLOCATE PREPARE stmt;

-- 同样为 schedule_adjust_log / schedule_unassigned_task ...
```

**Entity 补 `@TableLogic`**：

```diff
  @Getter @Setter
  @TableName("schedule_locked_item")
  public class ScheduleLockedItem {
      ...
+     @TableLogic
+     private Integer deleted;
  }
```
