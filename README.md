# 高校排课管理系统 V1 文档包

这是“基于 Spring Boot + Vue 的高校排课管理系统”第一版开发文档。

## 第一版定位

```text
基础数据管理 + 教学任务管理 + 手动排课 + 冲突检测 + 课表查询
```

## 文档目录

| 文件 | 作用 |
|---|---|
| 01_项目需求说明_PRD.md | 明确项目目标、范围、验收标准 |
| 02_技术架构.md | 固定技术栈、目录结构、接口风格 |
| 03_功能模块设计.md | 描述各功能模块 |
| 04_数据库设计.md | 定义核心数据库表 |
| 05_接口设计.md | 定义主要后端 API |
| 06_页面设计.md | 定义前端页面和菜单结构 |
| 07_开发阶段计划.md | 规定分阶段开发顺序 |
| 08_测试验收清单.md | 用于最终测试和检查 |
| CLAUDE.md | 给 AI 编程工具使用的最高优先级规则文件 |

## 使用建议

1. 先让 AI 阅读 `CLAUDE.md`
2. 再让 AI 阅读 `01_项目需求说明_PRD.md`
3. 开发某个阶段前，再补充对应文档
4. 严格按照 `07_开发阶段计划.md` 分阶段开发
5. 每完成一个阶段，都用 `08_测试验收清单.md` 检查

## 第一版不做

第一版不做自动排课、学生选课、教师端、学生端、调课申请、考试排课、AI 排课建议和复杂权限系统。
