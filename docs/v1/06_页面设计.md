## 3. 登录页

### 3.1 页面元素

- 系统名称
- 用户名输入框
- 密码输入框
- 登录按钮

### 3.2 交互规则

- 用户名和密码不能为空
- 登录成功后进入首页
- 登录失败显示后端返回的错误信息

## 10. 手动排课页

### 10.1 页面目标

选择教学任务、时间段、教室，保存排课结果。

### 10.2 搜索区

- 课程名称
- 教师姓名
- 班级名称
- 教室名称
- 星期
- 大节

### 10.3 排课表单

- 教学任务选择框
- 时间段选择框
- 教室选择框
- 备注

教学任务选择框建议展示：

```text
Java程序设计 / 张老师 / 计科1班 / 每周4节 / 已排1/2大节
```

### 10.4 操作

- 新增排课
- 删除排课
- 查看冲突提示

### 10.5 错误提示示例

```text
排课失败：张老师在周一第1-2节已有课程
排课失败：A101 教室在该时间段已被占用
排课失败：计科1班人数为60，当前教室容量为40
排课失败：实验课必须安排在实验室
```

## 11. 课表查询页

### 11.1 班级课表页

页面顶部选择班级，下方展示周课表。

### 11.2 教师课表页

页面顶部选择教师，下方展示周课表。

### 11.3 教室课表页

页面顶部选择教室，下方展示周课表。

### 11.4 课表样式

推荐格式：

```text
        周一        周二        周三        周四        周五
1-2节   Java        高数        空          英语        空
3-4节   空          数据库      体育        空          Java
5-6节   ...
7-8节   ...
```

每个单元格建议展示：

- 课程名
- 教师名
- 班级名
- 教室名

不同课表页面可以显示不同重点：

- 班级课表重点显示课程、教师、教室
- 教师课表重点显示课程、班级、教室
- 教室课表重点显示课程、教师、班级
