# 03_功能模块设计

## 1. 模块总览

第一版包含以下模块：

```text
登录模块
首页统计
教师管理
班级管理
教室管理
课程管理
教学任务管理
时间段数据
手动排课
冲突检测
课表查询
```

## 2. 登录模块

### 2.1 功能说明

管理员通过账号密码登录系统。

### 2.2 功能点

- 登录
- 退出登录
- 登录状态保存
- 路由访问控制
- 接口 token 校验

### 2.3 默认账号

开发环境可初始化一个管理员账号：

```text
用户名：admin
密码：123456
```

实际存储时密码应加密，不能明文存储。

## 3. 首页统计模块

### 3.1 功能说明

首页用于展示系统概况。

### 3.2 统计项

- 教师数量
- 班级数量
- 教室数量
- 课程数量
- 教学任务数量
- 已排课程数量
- 未排课程数量

## 4. 教师管理

### 4.1 字段

- 教师编号
- 教师姓名
- 所属学院/部门
- 联系电话
- 状态
- 备注

### 4.2 功能

- 新增教师
- 编辑教师
- 删除教师
- 查询教师
- 启用/停用教师

### 4.3 规则

- 教师编号不能重复
- 停用教师不能参与排课
- 已被教学任务使用的教师不建议物理删除，可使用逻辑删除

## 5. 班级管理

### 5.1 字段

- 班级名称
- 专业名称
- 年级
- 班级人数
- 班主任
- 状态
- 备注

### 5.2 功能

- 新增班级
- 编辑班级
- 删除班级
- 查询班级
- 启用/停用班级

### 5.3 规则

- 班级名称不能重复
- 班级人数用于教室容量检测
- 停用班级不能参与排课

## 6. 教室管理

### 6.1 字段

- 教室名称
- 教学楼
- 教室容量
- 教室类型
- 状态
- 备注

### 6.2 教室类型

第一版固定：

- 普通教室
- 多媒体教室
- 实验室
- 机房

### 6.3 功能

- 新增教室
- 编辑教室
- 删除教室
- 查询教室
- 启用/停用教室

### 6.4 规则

- 教室名称不能重复
- 停用教室不能参与排课
- 教室容量必须大于 0

## 7. 课程管理

### 7.1 字段

- 课程编号
- 课程名称
- 课程类型
- 课程性质
- 总学时
- 每周课时
- 备注

### 7.2 课程类型

第一版固定：

- 普通课
- 实验课
- 机房课
- 体育课

### 7.3 功能

- 新增课程
- 编辑课程
- 删除课程
- 查询课程

### 7.4 规则

- 课程编号不能重复
- 每周课时必须大于 0
- 总学时必须大于 0

## 8. 教学任务管理

### 8.1 功能说明

教学任务表示一条待排课任务：

```text
某课程 - 某教师 - 某班级 - 每周课时
```

### 8.2 字段

- 课程
- 教师
- 班级
- 每周课时
- 是否需要连续排课
- 任务状态
- 备注

### 8.3 功能

- 新增教学任务
- 编辑教学任务
- 删除教学任务
- 查询教学任务
- 查看是否已排课

### 8.4 规则

- 教师、班级、课程必须存在
- 停用教师不能创建任务
- 停用班级不能创建任务
- 每周课时必须大于 0
- 已经排课的教学任务，编辑时要谨慎处理

## 9. 时间段数据

### 9.1 功能说明

第一版时间段固定，不做页面维护。

### 9.2 固定规则

```text
周一到周五
每天 4 个大节
共 20 个时间段
```

大节：

- 第 1-2 节
- 第 3-4 节
- 第 5-6 节
- 第 7-8 节

## 10. 手动排课模块

### 10.1 功能说明

管理员选择教学任务、时间段、教室，系统校验后保存排课结果。

### 10.2 表单项

- 教学任务
- 时间段
- 教室
- 备注

### 10.3 保存前校验

- 教师是否冲突
- 班级是否冲突
- 教室是否冲突
- 教室容量是否足够
- 教室类型是否匹配课程类型
- 教学任务是否超过每周课时
- 教师、班级、教室是否启用

## 11. 课表查询模块

### 11.1 班级课表

选择班级后展示该班一周课程。

### 11.2 教师课表

选择教师后展示该教师一周课程。

### 11.3 教室课表

选择教室后展示该教室一周占用情况。

### 11.4 展示形式

采用周课表：

```text
        周一      周二      周三      周四      周五
1-2节   课程      空        课程      空        课程
3-4节   空        课程      空        课程      空
5-6节   ...
7-8节   ...
```
