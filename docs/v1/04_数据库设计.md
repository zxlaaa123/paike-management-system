# 04_数据库设计

## 1. 数据库说明

数据库使用 MySQL 8.x。

第一版共 8 张核心表：

```text
sys_user
teacher
class_info
classroom
course
teaching_task
time_slot
schedule
```

建议所有业务表包含：

- id
- create_time
- update_time
- deleted

其中 `deleted` 用于逻辑删除。

## 2. sys_user 用户表

| 字段名 | 类型 | 说明 |
|---|---|---|

## 7. teaching_task 教学任务表

| 字段名 | 类型 | 说明 |

| id | bigint | 主键 |

## 8. time_slot 时间段表

| 字段名 | 类型 | 说明 |
|---|---|---|
| id | bigint | 主键 |
| day_of_week | tinyint | 星期：1周一，2周二...5周五 |
| period | tinyint | 大节序号：1到4 |
| name | varchar(50) | 显示名称 |
| start_section | int | 开始节次 |
| end_section | int | 结束节次 |
| sort_order | int | 排序 |
| create_time | datetime | 创建时间 |
| update_time | datetime | 更新时间 |

固定生成 20 条数据：

- 周一第1-2节
- 周一第3-4节
- 周一第5-6节
- 周一第7-8节
- ...
- 周五第7-8节

## 9. schedule 排课结果表

| 字段名 | 类型 | 说明 |
|---|---|---|
| id | bigint | 主键 |
| task_id | bigint | 教学任务ID |
| course_id | bigint | 课程ID |
| teacher_id | bigint | 教师ID |
| class_id | bigint | 班级ID |
| classroom_id | bigint | 教室ID |
| time_slot_id | bigint | 时间段ID |
| remark | varchar(255) | 备注 |
| create_time | datetime | 创建时间 |
| update_time | datetime | 更新时间 |
| deleted | tinyint | 逻辑删除 |

说明：

schedule 表冗余保存 course_id、teacher_id、class_id，是为了查询课表时更方便。保存排课记录时，这些字段从 teaching_task 中同步得到。

## 10. 冲突检测 SQL 思路

### 10.1 教师冲突

同一时间段，同一教师，不能有两条未删除排课记录。

### 10.2 班级冲突

同一时间段，同一班级，不能有两条未删除排课记录。

### 10.3 教室冲突

同一时间段，同一教室，不能有两条未删除排课记录。

### 10.4 课时超限

一个教学任务已排 time_slot 数量不能超过：

```text
weekly_hours / 2
```

如果后续要按单小节排课，再改成更细粒度的节次表。
