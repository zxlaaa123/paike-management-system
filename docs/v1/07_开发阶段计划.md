# 07_开发阶段计划

## 1. 开发原则

第一版采用分阶段开发方式。每个阶段完成后必须能运行、能测试、能提交，不允许一次性生成大量不可运行代码。

开发顺序必须遵循：

```text
项目初始化
↓
后端基础框架
↓
前端基础框架
↓
登录模块
↓
基础数据管理
↓
教学任务管理
↓
时间段初始化
↓
手动排课
↓
冲突检测
↓
课表查询
↓
整体联调
```

## 2. 阶段 0：项目初始化

### 目标

创建前后端项目目录。

### 任务

- 创建 backend 目录
- 创建 frontend 目录
- 创建 docs 目录
- 初始化 README
- 确定环境变量和数据库连接方式

### 验收

- 项目目录清晰
- README 能说明如何启动项目

## 3. 阶段 1：后端基础框架

### 目标

搭建 Spring Boot 后端骨架。

### 任务

- 创建 Spring Boot 3 项目
- 配置 MySQL
- 配置 MyBatis Plus
- 配置统一返回结构
- 配置全局异常处理
- 配置跨域
- 创建健康检查接口

### 验收

- 后端能启动
- 访问健康检查接口返回正常

## 4. 阶段 2：前端基础框架

### 目标

搭建 Vue 3 前端骨架。

### 任务

- 创建 Vue 3 + Vite + TypeScript 项目
- 安装 Element Plus
- 配置 Vue Router
- 配置 Pinia
- 配置 Axios
- 创建基础布局

### 验收

- 前端能启动
- 能访问首页和登录页

## 5. 阶段 3：登录模块

### 目标

实现管理员登录。

### 任务

- 创建 sys_user 表
- 初始化 admin 用户
- 实现登录接口
- 实现 JWT 生成和校验
- 前端实现登录页
- 前端保存 token
- 路由守卫

### 验收

- 管理员能登录
- 未登录不能访问后台页面
- 登录后能进入首页

## 6. 阶段 4：基础数据管理

### 目标

实现教师、班级、教室、课程管理。

### 任务

- 教师管理后端接口
- 班级管理后端接口
- 教室管理后端接口
- 课程管理后端接口
- 对应前端页面
- 分页查询
- 新增、编辑、删除、启用/停用

### 验收

- 四个基础模块都能增删改查
- 数据能正确保存到数据库
- 页面表单校验基本可用

## 7. 阶段 5：教学任务管理

### 目标

实现教学任务管理。

### 任务

- 创建 teaching_task 表
- 实现教学任务 CRUD
- 查询时关联课程、教师、班级名称
- 前端实现教学任务页面
- 显示已排大节数和所需大节数

### 验收

- 可以创建教学任务
- 可以看到任务对应课程、教师、班级
- 可以查看任务排课进度

## 8. 阶段 6：时间段初始化

### 目标

初始化固定时间段。

### 任务

- 创建 time_slot 表
- 初始化 20 个时间段
- 提供时间段查询接口
- 前端下拉框可选择时间段

### 验收

- 数据库中有 20 个时间段
- 前端可以正常选择时间段

## 9. 阶段 7：手动排课

### 目标

实现排课记录保存和查询。

### 任务

- 创建 schedule 表
- 实现排课新增接口
- 实现排课删除接口
- 实现排课列表查询
- 前端实现手动排课页面

### 验收

- 可以选择教学任务、时间段、教室保存排课
- 可以删除排课记录
- 可以查询排课记录

## 10. 阶段 8：冲突检测

### 目标

实现排课核心业务校验。

### 任务

保存排课前检测：

- 教师冲突
- 班级冲突
- 教室冲突
- 容量不足
- 教室类型不匹配
- 任务课时超限
- 停用数据不可用

### 验收

- 故意制造教师冲突时，系统能拦截
- 故意制造班级冲突时，系统能拦截
- 故意制造教室冲突时，系统能拦截
- 容量不足时，系统能拦截
- 实验课安排普通教室时，系统能拦截

## 11. 阶段 9：课表查询

### 目标

实现三类课表展示。

### 任务

- 班级课表接口
- 教师课表接口
- 教室课表接口
- 前端周课表组件
- 三个课表查询页面

### 验收

- 选择班级能看到该班课表
- 选择教师能看到该教师课表
- 选择教室能看到该教室课表

## 12. 阶段 10：整体联调

### 目标

修复问题，保证第一版完整可演示。

### 任务

- 检查页面跳转
- 检查接口错误提示
- 检查数据初始化
- 检查冲突检测
- 检查课表展示
- 补充 README 启动说明

### 验收

完成 PRD 中的 12 条验收标准。
