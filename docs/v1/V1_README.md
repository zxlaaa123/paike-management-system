本目录用于存放第一版开发文档，第一版范围以 `CLAUDE.md` 为最高优先级。

## 第一版定位

```text
基础数据管理 + 教学任务管理 + 手动排课 + 冲突检测 + 课表查询
```

## Java 版本说明

- 项目基线与验收标准：`Java 17`
- 本地开发可临时使用 `Java 21` 运行与调试（Spring Boot 3 兼容）
- 提交前需确保代码不依赖仅 `Java 21` 才支持的语法/特性，以保证 `Java 17` 环境可构建运行
