# 05_接口设计

## 1. 接口约定

接口统一前缀：

```text
/api
```

统一返回结构：

```json
{
  "code": 200,
  "message": "success",
  "data": {}
}
```

分页返回结构：

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "records": [],
    "total": 0,
    "current": 1,
    "size": 10
  }
}
```

## 2. 登录接口

### 2.1 登录

```text
POST /api/auth/login
```

请求：

```json
{
  "username": "admin",
  "password": "123456"
}
```

响应：

```json
{
  "token": "jwt-token",
  "userInfo": {
    "id": 1,
    "username": "admin",
    "realName": "管理员"
  }
}
```

### 2.2 获取当前用户

```text
GET /api/auth/me
```

### 2.3 退出登录

```text
POST /api/auth/logout
```

## 10. 手动排课接口

### 10.1 查询排课记录

```text
GET /api/schedules
```

查询参数：

```text
courseName
teacherName
className
classroomName
dayOfWeek
period
page
size
```

### 10.2 新增排课

```text
POST /api/schedules
```

请求：

```json
{
  "taskId": 1,
  "timeSlotId": 1,
  "classroomId": 1,
  "remark": ""
}
```

保存前后端必须进行冲突检测。

### 10.3 删除排课

```text
DELETE /api/schedules/{id}
```

### 10.4 检查冲突

可选接口，用于前端提前提示：

```text
POST /api/schedules/check-conflict
```

请求：

```json
{
  "taskId": 1,
  "timeSlotId": 1,
  "classroomId": 1
}
```

响应：

```json
{
  "hasConflict": true,
  "message": "排课失败：张老师在周一第1-2节已有课程"
}
```

注意：即使有此接口，真正保存时仍必须再次检测。
