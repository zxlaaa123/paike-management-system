# V10 测试与验收清单：连续周段支持

## 1. 测试基准矩阵

所有冲突链路都以这组矩阵为准。
判定标准：同资源同物理时段下，只有实际自然周集合相交才算冲突。
V10 不验收 JSON 周模式或任意周集合，只验收 `week_type + start_week + end_week`。

| A | B | 预期 | 说明 |
|---|---|---|---|
| `ALL 1-8` | `ALL 9-16` | 不冲突 | 周段不相交 |
| `ALL 1-8` | `ODD 5-12` | 冲突 | 交集 5、7 |
| `ODD 1-8` | `EVEN 1-8` | 不冲突 | 同区间但奇偶互斥 |
| `ODD 1-8` | `EVEN 8-12` | 不冲突 | 交集区间只有 8，A 不含 8 |
| `ALL 8-8` | `ODD 1-9` | 不冲突 | 交集周为 8，B 不含 8 |
| `ODD 1-9` | `ODD 8-12` | 冲突 | 交集 9 |
| `EVEN 2-2` | `ALL 1-3` | 冲突 | 交集 2 |
| `ODD 21-21` | `ALL 1-20` | 非法或不冲突 | V10 默认最大周 20 |

## 4. 阶段 2：手动排课与方案冲突

### 4.1 ScheduleConflictService

扩展：

- `ScheduleConflictServiceTest`

用例：

- 同教师同 timeSlot：`ALL 1-8` + `ALL 9-16` 允许。
- 同教师同 timeSlot：`ALL 1-8` + `ODD 5-12` 拒绝。
- 同班级同 timeSlot：不相交允许，相交拒绝。
- 同教室同 timeSlot：不相交允许，相交拒绝。
- `excludeScheduleId` 编辑自身时不误报。
- 日上限按实际周集合计数。
- 同课同日按实际周集合计数。

### 4.2 SchedulePlanService

扩展：

- `SchedulePlanServiceTest`

用例：

- `refreshPlanConflictState` 对 `ALL 1-8` + `ALL 9-16` 不标冲突。
- `refreshPlanConflictState` 对 `ALL 1-8` + `ODD 5-12` 标冲突。
- `applyPlanInternal` 把 `startWeek/endWeek` 从 item 透传到 schedule。
- 已应用方案调整后正式课表周段不丢失。
- 应用方案前有周段冲突时拒绝应用。

### 4.3 ScheduleConflictReportService

扩展：

- `ScheduleConflictReportServiceTest`

用例：

- 同教师同 timeSlot 但实际周集合不相交：不生成冲突报告。
- 同教师同 timeSlot 且实际周集合相交：生成 `TEACHER_CONFLICT`。
- 班级、教室同理。
- 每日 overload 按实际周集合计数。
