# C-25 表单 Ref 类型调查

## 结论

已修复。

原问题部分成立：前端仍有 9 处 `formRef = ref()` 未声明 Element Plus 表单实例类型。这属于 TypeScript 类型约束问题，不是 Critical 级运行故障，但会让 `validate()` / `resetFields()` 等表单方法缺少明确类型保护。

## 本轮处理

为 9 处表单 ref 补齐 `FormInstance` 类型：

- `frontend/src/composables/useCrudForm.ts`
- `frontend/src/views/classInfo/ClassInfoView.vue`
- `frontend/src/views/classroom/ClassroomView.vue`
- `frontend/src/views/course/CourseView.vue`
- `frontend/src/views/schedule/ScheduleView.vue`
- `frontend/src/views/semester/SemesterView.vue`
- `frontend/src/views/teacher/TeacherUnavailableTimeView.vue`
- `frontend/src/views/teacher/TeacherView.vue`
- `frontend/src/views/teachingTask/TeachingTaskView.vue`

本轮只收紧类型，不改变表单验证和提交流程。

## 本轮验证

前端构建通过：

- `npm --prefix D:\paike\frontend run build`

并确认前端源码不再检出无泛型 `formRef = ref()`。
