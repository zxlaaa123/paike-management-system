# M-16 第9批（最后一批）Schedule 收口报告

## 侦察摘要

**Entity**: `Schedule.java`（10 view + 14 persistent = 24 字段）

**View 字段（10 个）**: `courseName`、`teacherName`、`className`、`timeLabel`、`dayOfWeek`、`periodNo`、`roomName`、`building`、`sourceTypeName`、`batchNo`

**填充路径**: `ScheduleService.fillRelations(List)` → 从 TimeSlot/Classroom/TeachingTask/Course/Teacher/ClassInfo/AutoScheduleBatch 批量查询后逐字段 set。`fillRelation(Schedule)` 委托 `fillRelations(singletonList)`。

**View 字段消费方**:
- **仅 Controller（6 端点）通过 Jackson 序列化读取**，零内部 Java 消费方。
- 所有 `List<Schedule>` / `Page<Schedule>` 出现（~27 文件）均在 Entity 世界：只读 `id`/`timeSlotId`/`classroomId`/`teachingTaskId`/`batchId` 等持久化列、不碰 view 字段。删 Entity view 字段后这些路径行为不变。

**Mapper XML**: `selectFilteredSchedulePage` 用 `s.*`、无 alias；`selectDailyConflictCounts` 直接返 DTO 不经过 Entity。

**范式**: 纯 fillRelations（Batch 1-4 系），无 alias、无两世界分界、无 Controller 层转换。复杂度低于预期——原「27 文件耦合」实为持久化列访问，全在 Entity 世界不受影响。

## VO

`ScheduleVo`（24 字段）：14 持久化（含 `deleted` 恒 0 + `createTime`/`updateTime`）+ 10 view。含 `fromEntity` 静态工厂（只拷 14 持久化列）。

## 五层改法

**① VO**: 新建 `ScheduleVo`，`@Data @NoArgsConstructor @AllArgsConstructor`，普通 POJO，保留 null 序列化。`fromEntity` 拷 14 持久化列。

**② Entity**: 删 10 个 `@TableField(exist = false)` view 字段（`@TableField` import 保留——`create_time`/`update_time` 仍用）。Entity 从 24 字段 → 14 持久化。

**③ Service**: `ScheduleService` 6 个方法（`list`/`getById`/`create`/`listByClass`/`listByTeacher`/`listByClassroom`）全部转 `ScheduleVo`：
- `list()`: Entity page → stream map `fromEntity` → `fillRelations(VO)` → 新建 `Page<ScheduleVo>`
- `getById()`: Entity → `fromEntity` → `fillRelation(VO)` → 返 VO
- `create()`: insert Entity → `fromEntity` → `fillRelation(VO)` → 返 VO
- `listByClass/listByTeacher/listByClassroom`: Entity list → stream map `fromEntity` → `fillRelations(VO)` → 返 `List<Vo>`
- `fillRelations`: `List<Schedule>` → `List<ScheduleVo>`，循环变量 `Schedule schedule` → `ScheduleVo vo`，setter 全部切 VO
- `fillRelation`: `Schedule` → `ScheduleVo`
- `delete()`、`checkConflict()` 不动（不涉 view 字段）

**④ Controller**: 6 端点全转 VO——`import Schedule` → `import ScheduleVo` + 返回类型 `Result<Page<Schedule>>` → `Result<Page<ScheduleVo>>`（list）/ `Result<Schedule>` → `Result<ScheduleVo>`（getById/create）/ `Result<List<Schedule>>` → `Result<List<ScheduleVo>>`（listByClass/listByTeacher/listByClassroom）
