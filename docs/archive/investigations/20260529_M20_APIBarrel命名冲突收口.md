# M-20 API barrel 命名冲突收口

## 结论

M-20 已整理。

`frontend/src/api/index.ts` 已经汇总大部分基础 API 和部分 v4/v5 API。剩余的 `v4ScheduleAnalysisApi` 与 `v5SimulationApi` 不能直接使用 `export *`，因为它们与既有模块存在顶层导出名冲突：

- `ScheduleRiskIssue`
- `ScheduleRiskList`
- `ScheduleScoreDetail`
- `ScheduleAdjustLog`

## 本轮修改

在 `frontend/src/api/index.ts` 中为两个冲突模块补命名空间导出：

- `export * as v4ScheduleAnalysisApi from './v4ScheduleAnalysisApi'`
- `export * as v5SimulationApi from './v5SimulationApi'`

这样调用方可以从 barrel 获取完整模块能力，同时避免把冲突类型暴露到顶层命名空间。

## 本轮验证

- 通过脚本确认直接 `export *` 会产生 4 个冲突导出名。
- `npm --prefix D:\paike\frontend run build` 通过。
