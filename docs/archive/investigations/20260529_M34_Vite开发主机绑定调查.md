# M-34 Vite 开发主机绑定调查

## 结论

已修复。

原问题部分成立：`frontend/vite.config.ts` 固定配置 `host: '0.0.0.0'`，会让 Vite 开发服务监听所有网卡。这不是生产漏洞，因为它只影响本地开发服务器，但默认暴露到局域网没有必要。

## 本轮处理

将开发服务监听地址改为默认仅本机：

- 默认 `DEV_SERVER_HOST` 为空时，Vite 绑定 `127.0.0.1`。
- 需要手机、平板或局域网设备联调时，可在本地 `.env.local` 设置 `DEV_SERVER_HOST=0.0.0.0`。
- `.env.example` 增加可选配置说明，但保持示例默认安全。

本轮不改 `npm run dev` 脚本。原因是当前风险来自配置文件默认值，收回默认 host 即可；命令行仍保持 Vite 标准入口。
