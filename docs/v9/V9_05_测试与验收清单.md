## 冲突矩阵（所有冲突类测试的基准）

以下矩阵定义 weekType 之间的冲突关系，**三套冲突检测实现 + 引擎版必须完全一致**：

```
         ALL    ODD    EVEN
ALL      冲突   冲突    冲突
ODD      冲突   冲突    不冲突
EVEN     冲突   不冲突  冲突
```

含义：
- ALL（全周）与任意 weekType 在同时段同资源冲突（全周课占满整个时段）
- ODD（单周）与 EVEN（双周）在同时段同资源**不冲突**（这是单双周的核心价值：共用时段）
- 同类 weekType 在同时段同资源冲突
