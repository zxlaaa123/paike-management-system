# V6_00_开发前检查记录

## 一、检查目的

V6 开发前必须确认 V1-V5 基础能力稳定，避免在不稳定基线上继续扩展治理能力。

V6 的开发原则是：

1. 不重写 V1-V5。
2. 不破坏已有接口。
3. 不改变正式课表写入边界。
4. 不让智能修复直接修改正式课表。
5. 先检查、再治理、后增强。
