# V6_08_测试与验收清单

## 一、验收目标

V6 验收重点不是验证新增排课能力，而是验证系统治理能力是否真实有效。

验收目标：

1. V1-V5 回归可执行、可查看、可追踪。
2. 数据一致性检查可发现关键边界问题。
3. 性能基线可记录关键操作耗时。
4. 审计日志可追踪关键写操作。
5. 数据库迁移和错误码机制可用。
