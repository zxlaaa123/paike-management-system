# V6_02_功能模块设计

## 一、模块总览

V6 由六个核心治理模块组成：

| 模块 | 说明 |
|---|---|
| 回归测试中心 | 管理 V1-V5 主链路回归结果 |
| 数据一致性检查中心 | 检查学期、方案、锁定、正式课表边界 |
| 性能基线中心 | 记录自动排课、局部重排、智能修复耗时 |
| 审计日志中心 | 追踪关键写操作 |
| 数据库迁移中心 | 查看数据库版本和迁移状态 |
| 错误码与提示中心 | 统一接口错误码和前端提示 |

## 二、当前实现校准（2026-06-07）

| 模块 | 当前状态 | V6 处理建议 |
|---|---|---|
| 回归测试中心 | V5 已有 `schedule_regression_test` 基础表 | 不重复建同语义表；先补批次/用例结果模型或复用后扩展 |
| 数据一致性检查中心 | V5 已有一致性检查服务和 `schedule_consistency_check` | 先复用 V5 能力，V6 只补跨模块治理视图和批次化记录 |
| 性能基线中心 | 当前未形成独立性能基线表/API | 可作为 V6 后续阶段 |
| 审计日志中心 | 已有 `system_audit_log`、审计服务、`/api/v6/audit-logs` | 继续补齐关键写路径审计覆盖 |
| 数据库迁移中心 | 当前仍以项目内 SQL 和 Java initializer 混合维护 | 暂不强行引入 Flyway/Liquibase，先做只读状态说明 |
| 错误码与提示中心 | 当前错误码治理未形成独立目录/API | 可在审计日志后推进 |

以下模块设计保留为目标形态；实际开发时以本节校准优先。

## 三、模块一：回归测试中心

### 2.1 职责

用于沉淀 V1-V5 核心功能的自动化回归结果。

### 2.2 核心能力

1. 创建回归批次。
2. 记录测试用例结果。
3. 查看失败原因。
4. 按版本筛选 V1-V5 用例。
5. 展示最近一次回归状态。

### 2.3 最小用例分组

| 分组 | 用例 |
|---|---|
| V1 | 基础数据、教学任务、手动排课、课表查询 |
| V2 | 禁排、规则配置、自动排课、评分、导出 |
| V3 | 学期、方案、应用、回滚、日志 |
| V4 | 分析、风险、局部调整、锁定、报告 |
| V5 | 修复建议、候选位置、试算、对比、一致性 |

## 四、模块二：数据一致性检查中心

### 3.1 职责

检查排课系统关键数据边界是否被破坏。

### 3.2 检查项

1. 正式课表是否存在无来源方案记录。
2. 方案明细是否和方案学期一致。
3. 风险、评分、修复建议是否绑定有效方案。
4. 已废弃方案是否被应用。
5. 锁定课程是否被局部重排修改。
6. 试算方案是否直接污染正式课表。
7. 跨学期任务是否被排入错误学期。

## 五、模块三：性能基线中心

### 4.1 职责

记录关键排课操作耗时和数据规模，避免后续改动导致性能退化。

### 4.2 监控对象

1. 自动排课。
2. 冲突检测。
3. 方案评分。
4. 风险诊断。
5. 候选位置生成。
6. 局部重排。
7. 试算方案生成。

### 4.3 指标

| 指标 | 说明 |
|---|---|
| taskCount | 教学任务数量 |
| scheduleCount | 课表明细数量 |
| candidateCount | 候选位置数量 |
| durationMs | 执行耗时 |
| success | 是否成功 |
| errorCode | 失败错误码 |

## 六、模块四：审计日志中心

### 5.1 职责

记录正式课表和排课方案关键写操作。

### 5.2 操作类型

1. 应用方案。
2. 回滚方案。
3. 手动排课。
4. 手动调整。
5. 锁定课程。
6. 解除锁定。
7. 应用试算方案。
8. 修改规则权重。

## 七、模块五：数据库迁移中心

### 6.1 职责

展示数据库结构版本，辅助确认部署环境是否完成升级。

### 6.2 能力

1. 查看当前数据库版本。
2. 查看已执行迁移脚本。
3. 查看迁移执行时间。
4. 查看迁移成功或失败状态。

## 八、模块六：错误码与提示中心

### 7.1 职责

统一后端错误码和前端展示提示，减少静默失败和模糊错误。

### 7.2 错误分类

| 分类 | 示例 |
|---|---|
| AUTH | 未登录、权限不足、CSRF 失败 |
| VALIDATION | 参数缺失、状态不允许 |
| CONFLICT | 教师冲突、教室冲突、班级冲突 |
| SEMESTER | 学期不一致、当前学期不存在 |
| PLAN | 方案不存在、方案已废弃、试算方案不可直接应用 |
| LOCK | 锁定课程不可修改 |
| SYSTEM | 数据库异常、未知错误 |
