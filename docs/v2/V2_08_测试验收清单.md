## 16. 常见失败情况检查

如果自动排课结果很少，应检查：

```text
教师禁排时间是否过多
教室容量是否不足
教室类型是否不匹配
排课规则是否过严
教学任务每周课时是否过大
已有手动排课是否占用了大量时间段
可用教室数量是否太少
```

## 17. 不合格情况

出现以下情况，V2 不算通过：

```text
自动排课能生成冲突课表
未排任务没有原因
教师禁排时间不生效
自动排课覆盖手动排课但没有提示
冲突报告无法生成
课表评分没有扣分说明
V1 原有手动排课功能被破坏
```
