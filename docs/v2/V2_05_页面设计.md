# V2_05_页面设计

## 1. 页面设计原则

V2 页面在 V1 的基础上扩展，不推翻原有页面结构。

V1 已有页面：

```text
登录页
首页统计页
教师管理页
班级管理页
教室管理页
课程管理页
教学任务管理页
手动排课页
班级课表页
教师课表页
教室课表页
```

V2 新增页面：

```text
教师禁排时间页
排课规则配置页
自动排课页
未排任务页
排课冲突报告页
课表评分页
课表导出功能
```

## 2. V2 菜单结构建议

V2 菜单可以调整为：

```text
首页

基础数据管理
  - 教师管理
  - 班级管理

  - 课程管理

教学管理
  - 教学任务管理
```

## 4. 教师禁排时间页

### 4.1 页面目标

用于维护教师不可排课的时间段。

### 4.2 搜索区

包含：

```text
教师姓名
时间段
状态
```

### 4.3 表格列

包含：

```text
教师姓名
所属部门
禁排时间段
禁排原因
状态
创建时间
操作
```

### 4.4 操作按钮

```text
新增禁排时间
编辑
删除
启用/停用
```

### 4.5 表单字段

```text
教师
时间段
禁排原因
状态
备注
```

### 4.6 交互要求

- 教师选择框只显示启用教师
- 时间段选择框使用 V1 固定 20 个时间段
- 同一教师同一时间段不能重复设置
- 保存失败时显示后端错误信息

### 4.7 示例提示

```text
保存失败：张老师在周三第5-6节已存在禁排时间
```

## 5. 排课规则配置页

### 5.1 页面目标

用于配置自动排课使用的全局规则。

### 5.2 页面形式

推荐使用表单卡片，不建议做复杂表格。

### 5.3 配置项

```text
教师每天最多课程大节数
班级每天最多课程大节数
是否优先上午排课
是否避免周五下午排课
是否允许同一课程同一天重复出现
```

### 5.4 表单控件建议

| 配置项 | 控件 |
|---|---|
| 教师每天最多课程大节数 | 数字输入框 |
| 班级每天最多课程大节数 | 数字输入框 |
| 是否优先上午排课 | 开关 |
| 是否避免周五下午排课 | 开关 |
| 是否允许同一课程同一天重复出现 | 开关 |

### 5.5 操作按钮

```text
保存配置
恢复默认配置
```

### 5.6 默认配置

```text
教师每天最多 3 个大节
班级每天最多 4 个大节
优先上午排课：开启
避免周五下午：开启
允许同一课程同一天重复出现：关闭
```

## 6. 自动排课页

### 6.1 页面目标

用于执行一键自动排课，并展示执行结果。

这是 V2 的核心页面。

### 6.2 页面区域

建议分为四个区域：

```text
1. 自动排课设置区
2. 待排教学任务区
3. 执行结果区
4. 最近批次记录区
```

### 6.3 自动排课设置区

表单项：

```text
参与任务范围
是否清空旧自动排课结果
是否清空全部排课结果
```

参与任务范围建议：

```text
全部未排满任务
手动选择任务
```

清空选项说明：

```text
清空旧自动排课结果：只清空系统自动生成的排课记录
清空全部排课结果：包含手动排课记录，危险操作，默认关闭
```

### 6.4 待排教学任务区

表格列：

```text
课程名称
教师姓名
班级名称
每周课时
需要大节数
已排大节数
剩余大节数
状态
```

如果选择“手动选择任务”，表格需要支持多选。

### 6.5 执行按钮

按钮名称：

```text
一键自动排课
```

点击前需要二次确认：

```text
确定开始自动排课吗？系统将根据当前规则自动生成排课结果。
```

如果选择“清空全部排课结果”，提示要更明显：

```text
危险操作：该操作会清空手动排课记录，是否继续？
```

### 6.6 执行结果区

自动排课完成后展示：

```text
批次号
执行状态
参与任务数
成功任务数
未排任务数
生成排课记录数
执行耗时
结果说明
```

### 6.7 快捷操作

执行完成后提供按钮：

```text
查看未排任务
查看课表
生成冲突报告
生成课表评分
```

```text
剩余大节数
```

### 8.2 页面操作

顶部按钮：

```text

清空报告
```

### 8.3 搜索区

```text
报告编号
冲突类型
冲突对象类型
冲突对象名称
```

### 8.4 表格列

```text
报告编号
冲突类型
冲突对象
冲突时间
冲突说明
处理建议
创建时间
```

### 8.5 冲突类型显示

建议用标签展示：

```text
教师冲突
班级冲突
教室冲突
容量不足
教室类型不匹配
教师禁排冲突
任务未排满
教师当天课程过多
班级当天课程过多
```

### 8.6 处理建议示例

```text
建议调整其中一门课程到其他时间段
建议更换容量更大的教室
建议将实验课调整到实验室
建议放宽教师禁排时间或减少该教师教学任务
```

## 9. 课表评分页

### 9.1 页面目标

展示当前课表质量评分、扣分项和优化建议。

### 9.2 页面结构

建议分为：

```text
评分总览
扣分明细
优化建议
评分历史
```

### 9.3 评分总览

展示：

```text
当前分数
评分等级
硬冲突数量
未排满任务数量
教师超负荷数量
班级超负荷数量
周五下午课程数量
```

### 9.4 分数等级

```text
90-100：优秀
80-89：良好
70-79：一般
60-69：较差
60以下：需要调整
```

### 9.5 操作按钮

```text
重新评分
查看冲突报告
查看未排任务
```

### 9.6 扣分明细示例

```text
2 个教学任务未排满：-8 分
1 名教师当天课程过多：-3 分
周五下午课程较多：-3 分
```

### 9.7 优化建议示例

```text
建议优先处理未排满任务
建议调整课程过于集中的教师课表
建议减少周五下午课程
```

## 12. 页面开发优先级

建议开发顺序：

```text
1. 教师禁排时间页
2. 排课规则配置页
3. 自动排课页
4. 未排任务页
5. 冲突报告页
6. 课表评分页
7. 课表导出按钮增强
```

优先保证自动排课链路完整，再做评分和导出。
