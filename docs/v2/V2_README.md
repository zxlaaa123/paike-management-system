# 高校排课管理系统 V2 文档说明

## 1. V2 版本名称

```text
V2：规则化自动排课与排课优化版
```

## 2. V2 版本定位

V2 是在 V1 基础上的增强版本。

V1 已完成：

```text
基础数据管理
教学任务管理
手动排课
冲突检测
课表查询
```

V2 新增：

```text
教师禁排时间
排课规则配置
规则化自动排课
未排任务列表
排课冲突报告
课表评分
Excel 导出
```

V2 目标不是做复杂研究级算法，而是让系统从“手动排课管理系统”升级为“具备一定智能化能力的排课辅助系统”。

## 6. 推荐开发方式

V2 不建议一次性全部开发。

推荐按阶段给 AI 编程工具下任务：

```text
第一步：阅读 CLAUDE.md 和 V2_CLAUDE追加规则.md
第二步：阅读 V2_07_开发阶段计划.md
第三步：只开发当前阶段
第四步：完成后运行项目并测试
第五步：再进入下一阶段
```

## 7. V2 阶段顺序

```text
阶段 0：V1 代码检查与数据库备份
阶段 1：V2 数据库扩展
阶段 2：教师禁排时间模块
阶段 3：排课规则配置模块
阶段 4：手动排课增强
阶段 5：自动排课批次与未排任务基础结构
阶段 6：规则化自动排课核心逻辑
阶段 7：自动排课前端页面
阶段 8：未排任务页面
阶段 9：排课冲突报告
阶段 10：课表评分
阶段 11：Excel 导出
阶段 12：首页统计增强
阶段 13：整体联调与验收
```

## 8. V2 核心闭环

V2 最终应形成以下流程：

```text
设置教师禁排时间
↓
配置排课规则
↓
一键自动排课
↓
查看自动排课结果
↓
查看未排任务原因
↓
查看课表
↓
生成冲突报告
↓
生成课表评分
↓
导出课表
```

## 9. V2 最重要的功能

V2 最重要的不是 Excel 导出，也不是评分页面，而是：

```text
一键自动排课
未排任务原因
冲突报告
```

这三个功能决定 V2 是否真正从 V1 升级。

## 10. V2 自动排课定位

V2 自动排课采用：

```text
规则化遍历算法
```

不要引入：

```text
遗传算法
模拟退火
Timefold Solver
复杂回溯搜索
```

V2 的排课算法只需要做到：

```text
自动避开明显冲突
尽量安排大部分任务
排不了的任务说明原因
管理员可以手动调整
```

这已经足够作为毕业设计的“智能排课”功能。

## 11. V2 最低验收标准

V2 最低完成：

```text
教师禁排时间
排课规则配置
一键自动排课
未排任务列表
冲突报告
课表评分
```

Excel 导出建议完成，但如果时间紧，可以放到 V2 后期增强。
