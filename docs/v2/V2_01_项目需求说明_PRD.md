# V2_01_项目需求说明 PRD

## 1. 版本名称

高校排课管理系统 V2：规则化自动排课与排课优化版

## 2. V2 版本定位

V1 已经完成基础排课闭环：

```text
基础数据管理
教学任务管理
手动排课
冲突检测
课表查询
```

V2 在 V1 的基础上继续升级，目标是让系统从“手动排课管理系统”提升为“具备一定智能化能力的排课辅助系统”。

V2 的核心不是研究复杂算法，而是实现一套可控、可解释、适合毕业设计展示的规则化自动排课功能。

## 3. V2 核心目标

V2 要实现以下能力：

```text
配置排课规则
设置教师禁排时间
选择教学任务
一键自动排课
自动避开冲突
生成未排任务原因
生成排课冲突报告
对课表结果进行评分
支持课表导出 Excel
```

V2 的主线流程为：

```text
管理员登录系统
↓
维护基础数据和教学任务
↓
配置教师禁排时间和排课规则
↓
点击一键自动排课
↓
系统按规则尝试安排课程
↓
生成排课结果和未排任务列表
↓
查看冲突报告和课表评分
↓
导出班级/教师/教室课表
```

## 4. V2 与 V1 的关系

V2 不推翻 V1，而是在 V1 基础上扩展。

V1 负责：

- 基础数据
- 教学任务
- 手动排课
- 基础冲突检测
- 课表查询

V2 增加：

- 简单自动排课
- 教师禁排时间
- 排课规则配置
- 未排任务列表
- 冲突报告
- 课表评分
- Excel 导出

## 5. V2 功能范围

### 5.1 简单自动排课

管理员可以选择一批教学任务，点击“一键自动排课”。

系统根据时间段、教室、教师、班级、课程类型等条件，自动寻找可用排课位置。

第一版自动排课采用规则遍历方式，不使用遗传算法、Timefold Solver 或复杂优化求解器。

基本逻辑：

```text
遍历教学任务
↓
遍历可用时间段
↓
遍历可用教室
↓
检查教师、班级、教室、容量、类型、禁排时间等规则
↓
符合条件则保存排课结果
↓
不符合则尝试下一个位置
```

### 5.2 教师禁排时间

管理员可以为教师设置不可排课时间。

例如：

```text
张老师：周三第5-6节不可排课
李老师：周五第7-8节不可排课
```

手动排课和自动排课都必须检查教师禁排时间。

### 5.3 排课规则配置

V2 增加简单规则配置。

建议支持：

- 教师每天最多课程大节数
- 班级每天最多课程大节数
- 是否避免周五下午排课
- 是否优先安排上午课程
- 是否允许同一课程同一天重复出现

第一版规则配置不需要做得很复杂，先支持全局配置即可。

### 5.4 未排任务列表

自动排课完成后，如果部分教学任务无法排满，系统需要记录未排原因。

未排原因示例：

- 没有可用时间段
- 没有符合类型的教室
- 教室容量不足
- 教师禁排时间限制
- 教师时间冲突
- 班级时间冲突

### 5.5 排课冲突报告

V1 的冲突检测主要发生在保存排课时。

V2 增加“一键检测当前课表”功能，用于生成完整的冲突报告。

报告内容包括：

- 教师冲突
- 班级冲突
- 教室冲突
- 容量异常
- 教室类型异常
- 教师禁排时间冲突
- 教学任务未排满

### 5.6 课表评分

V2 增加排课质量评分，用于展示当前课表的合理程度。

评分不要求非常科学，但必须可解释。

评分维度建议：

- 是否存在硬冲突
- 教学任务完成度
- 教师课程分布是否均衡
- 班级课程分布是否均衡
- 是否尽量避免周五下午
- 是否减少教师连续上课过多

评分可以用百分制。

例如：

```text
当前课表评分：86 分
扣分项：
- 2 个教学任务未排满：-8 分
- 1 名教师当天课程过多：-3 分
- 周五下午课程较多：-3 分
```

### 5.7 Excel 导出

支持导出：

- 班级课表 Excel
- 教师课表 Excel
- 教室占用表 Excel

导出功能用于毕业设计展示和实际使用场景补充。

## 6. V2 不做的功能

以下功能不进入 V2：

- 遗传算法
- Timefold Solver
- 学生选课
- 教师端
- 学生端
- 考试排课
- 调课审批流程
- 多学期管理
- 多校区管理
- AI 排课建议
- 移动端适配

这些可以作为 V3 或论文展望。

## 7. V2 验收标准

V2 完成后必须能演示：

1. 可以设置教师禁排时间
2. 可以配置基础排课规则
3. 可以点击一键自动排课
4. 自动排课能避开教师、班级、教室冲突
5. 自动排课能检查教室容量
6. 自动排课能检查教室类型
7. 自动排课能避开教师禁排时间
8. 自动排课失败时能记录未排原因
9. 可以查看未排任务列表
10. 可以生成排课冲突报告
11. 可以查看课表评分和扣分原因
12. 可以导出班级课表 Excel
13. 可以导出教师课表 Excel
14. 可以导出教室占用表 Excel

## 8. V2 开发原则

- 不推翻 V1 数据结构，优先在 V1 上扩展
- 自动排课先做规则版，不追求最优解
- 所有规则必须后端校验
- 自动排课过程要有结果反馈
- 未排任务必须说明原因
- 冲突报告必须清晰可读
- 课表评分必须可解释
- 不提前引入复杂算法框架
