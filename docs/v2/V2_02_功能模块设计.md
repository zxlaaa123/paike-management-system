## 2. 教师禁排时间管理

### 2.1 功能说明

教师禁排时间用于记录某个教师在某些时间段不能被安排课程。

例如：

```text
张老师 周三第5-6节 不排课
李老师 周五第7-8节 不排课
```

### 2.2 字段建议

```text
教师
时间段
原因
状态
备注
```

### 2.3 功能点

- 新增禁排时间
- 编辑禁排时间
- 删除禁排时间
- 查询教师禁排时间
- 按教师查看禁排时间列表

### 2.4 业务规则

- 同一教师同一时间段不能重复设置禁排
- 停用教师不能新增禁排时间
- 手动排课时必须检查教师禁排时间
- 自动排课时必须跳过教师禁排时间

### 2.5 错误提示示例

```text
排课失败：张老师在周三第5-6节设置了禁排时间
```

## 3. 排课规则配置

### 3.1 功能说明

排课规则配置用于控制自动排课的偏好和限制。

V2 先做全局规则，不做按学院、专业、班级的复杂规则。

### 3.2 建议规则

| 规则 | 说明 |
|---|---|
| 教师每天最多课程大节数 | 避免教师一天课程过多 |
| 班级每天最多课程大节数 | 避免班级一天课程过多 |
| 是否优先上午排课 | 自动排课时优先尝试上午时间段 |
| 是否避免周五下午 | 自动排课时尽量不安排周五第5-8节 |
| 是否允许同一课程同一天重复出现 | 控制同一个班同一门课是否能一天出现多次 |

### 3.3 功能点

- 查看当前规则
- 修改规则配置
- 恢复默认规则

### 3.4 默认规则建议

```text
教师每天最多 3 个大节
班级每天最多 4 个大节
优先上午排课：开启
避免周五下午：开启
允许同一课程同一天重复出现：关闭
```

## 4. 自动排课模块

### 4.1 功能说明

自动排课是 V2 的核心功能。

管理员选择需要排课的教学任务，点击“一键自动排课”，系统自动尝试为教学任务分配时间段和教室。

### 4.2 页面操作

- 选择需要参与自动排课的教学任务
- 选择是否清空已有自动排课结果
- 点击一键自动排课
- 查看自动排课结果

### 4.3 自动排课基础逻辑

```text
读取待排教学任务
↓
根据每周课时计算需要排几个大节
↓
遍历时间段
↓
遍历教室
↓
调用冲突检测服务
↓
符合条件则保存排课结果
↓
无法安排则记录未排原因
```

### 4.4 自动排课必须检查

- 教师时间冲突
- 班级时间冲突
- 教室时间冲突
- 教室容量
- 教室类型
- 教师禁排时间
- 教师每天最多课程数
- 班级每天最多课程数
- 同一课程同一天重复限制
- 是否尽量避免周五下午

### 4.5 自动排课结果

自动排课结束后返回：

```text
总任务数
成功安排数量
未排任务数量
生成排课记录数量
未排原因列表
```

## 5. 未排任务管理

### 5.1 功能说明

未排任务用于展示自动排课过程中没有成功安排的任务。

这可以让用户知道系统为什么没有排满。

### 5.2 字段建议

```text
教学任务
课程
教师
班级
需要大节数
已排大节数
剩余大节数
未排原因
创建时间
```

### 5.3 未排原因示例

```text
没有可用时间段
没有符合课程类型的教室
所有可用教室容量不足
教师禁排时间过多
教师时间冲突
班级时间冲突
排课规则限制过严
```

### 5.4 功能点

- 查看未排任务列表
- 按课程、教师、班级查询
- 清空未排记录
- 根据未排原因手动调整排课

## 6. 排课冲突报告

### 6.1 功能说明

冲突报告用于对当前课表进行整体检查。

V1 是保存时检测单次排课冲突。  
V2 增加全局扫描能力。

### 6.2 检测内容

- 教师冲突
- 班级冲突
- 教室冲突
- 容量不足
- 教室类型不匹配
- 教师禁排时间冲突
- 教学任务未排满
- 教师当天课程过多
- 班级当天课程过多

### 6.3 报告字段

```text
冲突类型
冲突对象
冲突时间
涉及课程
冲突说明
处理建议
```

### 6.4 处理建议示例

```text
建议调整其中一门课程到其他时间段
建议更换容量更大的教室
建议将实验课调整到实验室
建议放宽教师禁排时间或减少该教师教学任务
```

## 7. 课表评分模块

### 7.1 功能说明

课表评分用于对当前排课结果进行量化评价。

评分采用百分制，主要用于展示系统的优化能力。

### 7.2 评分维度

| 维度 | 说明 |
|---|---|
| 硬冲突 | 教师、班级、教室是否冲突 |
| 任务完成度 | 教学任务是否排满 |
| 教师均衡性 | 教师课程是否过度集中 |
| 班级均衡性 | 班级课程是否过度集中 |
| 时间偏好 | 是否尽量安排在上午 |
| 周五下午控制 | 是否减少周五下午课程 |

### 7.3 评分结果

返回内容包括：

```text
总分
评分等级
扣分项
优化建议
```

评分等级建议：

```text
90-100：优秀
80-89：良好
70-79：一般
60-69：较差
60以下：需要调整
```

## 8. Excel 导出模块

### 8.1 功能说明

支持导出不同类型课表。

### 8.2 导出类型

- 班级课表
- 教师课表
- 教室占用表

### 8.3 导出格式

文件格式：

```text
.xlsx
```

表格结构沿用前端周课表形式。

### 8.4 推荐实现

后端可使用：

- EasyExcel
- Apache POI

优先选择实现简单、稳定的方案。

```text
第一优先级：
1. 教师禁排时间
2. 自动排课
3. 未排任务列表

第二优先级：

```
