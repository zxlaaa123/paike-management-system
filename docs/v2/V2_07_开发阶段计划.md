# V2_07_开发阶段计划

## 1. V2 开发目标

V2 的目标是在 V1 基础上增加规则化自动排课能力，并补充排课分析与导出功能。

V2 不推翻 V1，而是渐进式扩展。

V2 核心新增能力：

```text
教师禁排时间
排课规则配置
规则化自动排课
未排任务记录
排课冲突报告
课表评分
Excel 导出
```

## 2. 开发原则

V2 开发必须遵循以下原则：

1. 不重构 V1 核心结构，除非确实必要
2. 不提前引入遗传算法、Timefold Solver 等复杂算法
3. 自动排课先做规则遍历版，保证可运行和可解释
4. 每个阶段完成后都要能启动项目
5. 所有业务规则必须在后端校验
6. 前端只做交互提示，不能替代后端规则判断
7. 未排任务必须记录原因
8. 自动排课不能静默失败
9. 先保证主流程，再做评分和导出
10. 不扩大到学生端、教师端、选课系统、考试排课

## 3. V2 开发顺序总览

推荐顺序：

