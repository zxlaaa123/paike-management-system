## 发现的问题

### 问题 1：前端弹窗下拉框无法通过 Playwright 正常操作

- **描述**：Element Plus 弹窗内的 el-select 下拉框，其下拉选项通过 `append-to-body` 追加到 body，导致 Playwright 的 click 操作被 `el-overlay-dialog` 遮挡
- **影响**：前端自动化测试无法正常操作弹窗内的下拉框
- **建议**：这是 Element Plus 组件的已知行为，不影响实际用户使用。如需自动化测试，可通过 API 接口直接测试后端逻辑

### 问题 2：首页统计数据为占位符

- **描述**：首页统计卡片显示 "--"，提示"阶段 2 仅搭建基础框架"
- **影响**：无功能影响，属于预期行为
- **建议**：后续阶段接入统计数据

### 问题 3：前端控制台存在 Element Plus 废弃 API 警告

- **描述**：继续回归过程中，控制台未出现 error，但出现 2 条 `ElementPlusError` warning，内容为 `[el-radio] [API] label act as value is about to be deprecated in version 3.0.0, please use value instead`
- **影响**：当前不阻塞功能，但后续升级 Element Plus 3.x 时存在兼容性风险
- **建议**：将相关 `el-radio` 用法从 `label` 充当值改为显式 `value`
