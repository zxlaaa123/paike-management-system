# V7 统计与展示补全版

V7 的目标不是新增复杂主流程，而是把 V1-V6 中已经暴露的展示缺口、统计占位和自动化验收不一致问题收口。

推荐开发顺序：

1. `V7_01_版本需求说明.md`
2. `V7_02_功能模块设计.md`
3. `V7_03_API接口设计.md`
4. `V7_04_前端页面设计.md`
5. `V7_05_开发阶段计划.md`
6. `V7_06_测试与验收清单.md`

最终交付文档：

1. `V7_FINAL_项目最终说明.md`
2. `V7_FINAL_最终验收记录.md`
3. `V7_FINAL_问题收口执行计划.md`

核心原则：

1. 不重写 V1-V6 主链路。
2. 优先补用户能直接看见的展示字段和统计值。
3. 保持现有接口兼容，新增字段优先采用可选字段。
4. 每个阶段必须有后端测试、前端类型检查、前端构建和必要 Playwright 验证。
