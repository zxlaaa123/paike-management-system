# V7 前端页面设计

## 一、排课方案列表

### 1.1 页面路径

```text
/schedule-plans
```

### 1.2 改造点

1. 学期列优先展示 `semesterName`。
2. 策略列优先展示 `strategyName`。
3. 原始 ID 和策略码可作为次级信息或 tooltip。

## 二、统计分析页

### 2.1 页面路径

```text
/statistics
```

### 2.2 改造点

1. 教师工作量表展示真实 `maxContinuousPeriods`。
2. 对连续节次过高的教师做轻量标记。
3. 保持原有教师工作量、教室利用率、班级均衡度结构。

## 三、首页

### 3.1 页面路径

```text
/dashboard
```

### 3.2 改造点

1. 增加当前学期业务概览。
2. 增加 V6 治理摘要。
3. 增加未排任务和冲突风险提示。
4. 避免展示 `--` 作为长期占位。

## 四、性能基线页

### 4.1 页面路径

```text
/v6/performance-baselines
```

### 4.2 改造点

1. 增加最近耗时趋势。
2. 增加慢操作标记。
3. 保留现有列表、筛选和汇总卡片。

## 五、测试页面要求

1. 所有新增字段缺失时页面不崩。
2. 表格文本不能溢出。
3. 移动端可横向滚动表格或保持布局稳定。
4. Playwright smoke 必须覆盖关键入口。
