# V7 开发阶段计划

## 阶段 0：现状复核

目标：确认 V7 文档与当前代码一致。

任务：

1. 复核 `SchedulePlanVo.semesterName/strategyName` 当前是否仍未填充。
2. 复核 `TeacherWorkloadVo.maxContinuousPeriods` 当前是否仍恒为 0。
3. 复核首页统计当前字段。
4. 复核 V6 性能基线当前能力。

验收：

1. 输出现状调查记录。
2. 不改业务代码。

## 阶段 1：排课方案展示字段补全

目标：补齐方案列表中的学期名称和策略名称。

任务：

1. 后端填充 `semesterName`。
2. 后端填充 `strategyName`。
3. 前端展示字段接入。
4. 增加后端测试。

验收：

1. 方案列表能看到学期名称。
2. 方案列表能看到策略中文名。
3. `mvn test`、`npx vue-tsc -b`、`npx vite build` 通过。

完成情况：

1. 已完成后端 `SchedulePlanVo` 列表/详情展示字段填充。
2. 已完成前端方案列表学期名称、策略中文名展示。
3. 已新增后端展示字段单测。
4. 已验证：`mvn -q test`、`npx vue-tsc -b`、`npx vite build`。

## 阶段 2：教师连续节次统计

目标：`maxContinuousPeriods` 返回真实统计值。

任务：

1. 实现连续节次统计函数。
2. 支持正式课表和方案课表。
3. 前端统计页展示连续节次。
4. 增加边界测试。

验收：

1. 构造同一天连续 3 大节时返回 3。
2. 不连续课程不会被误算。

完成情况：

1. 已实现教师同一天最长连续大节统计。
2. 已支持正式课表和方案课表两种来源。
3. 已完成前端教师工作量表格展示。
4. 已新增连续 3 大节和不连续断点测试。

## 阶段 3：首页统计增强

目标：首页展示当前学期关键业务和治理状态。

任务：

1. 后端 dashboard 接口补字段。
2. 前端首页卡片接入。
3. 空数据状态可读。

验收：

1. 首页不出现长期占位 `--`。
2. 当前学期、任务、未排、治理摘要可见。

完成情况：

1. 已扩展 dashboard 接口，补齐课程数、教学任务数、未排任务数、冲突数、应用方案状态和治理摘要。
2. 已将首页基础统计和治理摘要改为单 dashboard 接口驱动。
3. 已新增后端 dashboard 统计字段测试。

## 阶段 4：性能基线趋势增强

目标：性能基线中心能判断基础趋势和慢操作。

任务：

1. 后端增加趋势查询。
2. 前端增加趋势展示。
3. 增加慢操作标记。

验收：

1. 趋势接口返回最近记录。
2. 页面能展示耗时变化和慢操作。

## 阶段 5：E2E 认证统一

目标：旧 Playwright 测试统一使用 cookie 登录。

任务：

3. 改造 `tests/stage7.spec.ts`。
4. 改造 `tests/stage9.spec.ts`。

验收：
