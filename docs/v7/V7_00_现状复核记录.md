# V7 阶段 0 现状复核记录

复核日期：2026-06-08

## 一、复核结论

V7 的“统计与展示补全版”定位与当前代码现状匹配。当前最值得优先处理的是排课方案列表展示字段和教师连续节次统计，其次是首页治理摘要、性能趋势和 E2E 认证统一。

本阶段只做现状复核和文档记录，未改业务代码。

## 二、排课方案展示字段

### 2.1 当前代码状态

相关文件：

1. `backend/src/main/java/com/paike/scheduler/controller/SchedulePlanController.java`
2. `backend/src/main/java/com/paike/scheduler/service/SchedulePlanService.java`
3. `backend/src/main/java/com/paike/scheduler/service/vo/SchedulePlanVo.java`

复核结果：

1. `SchedulePlanVo` 保留 `semesterName` 和 `strategyName` 字段。
2. `SchedulePlanVo.fromEntity()` 只拷贝持久化字段，没有填充 `semesterName` 和 `strategyName`。
3. `SchedulePlanController.list()` 当前返回 `Result<Page<SchedulePlan>>`，不是 `Page<SchedulePlanVo>`。
4. `SchedulePlanController.getById()` 返回 `SchedulePlanVo.fromEntity(planService.getById(id))`，同样没有填充展示字段。

### 2.2 阶段 1 开发判断

阶段 1 不应只补 `SchedulePlanVo.fromEntity()`，而应：

1. 将方案列表返回从 `Page<SchedulePlan>` 收口到 `Page<SchedulePlanVo>`。
2. 在 service 层批量填充 `semesterName`。
3. 在 service 层填充 `strategyName`。
4. 保持现有分页结构和字段兼容。

## 三、教师连续节次统计

### 3.1 当前代码状态

相关文件：

1. `backend/src/main/java/com/paike/scheduler/service/ScheduleStatisticsService.java`
2. `backend/src/main/java/com/paike/scheduler/service/vo/TeacherWorkloadVo.java`

复核结果：

1. `ScheduleStatisticsService.teacherWorkload()` 支持正式课表和方案课表：
   - 不传 `planId` 时使用正式课表。
   - 传 `planId` 时使用方案明细。
2. `TeacherWorkloadVo.maxContinuousPeriods` 字段存在。
3. 当前实现明确写死：`vo.setMaxContinuousPeriods(0)`。
4. `TeacherWorkloadVo` 注释明确该字段为历史占位，前端当前不主动读取该字段。

### 3.2 阶段 2 开发判断

阶段 2 应在统计聚合时保留每天的 period 序列，并计算单日最大连续段长度。

建议口径：

1. 按教师分组。
2. 再按 weekday/dayOfWeek 分组。
3. 对同一天的 period/startPeriod 排序。
4. 连续 period 计入同一连续段。
5. 跨天不连续。

## 四、首页统计

### 4.1 当前代码状态

相关文件：

1. `backend/src/main/java/com/paike/scheduler/service/ScheduleStatisticsService.java`
2. `backend/src/main/java/com/paike/scheduler/service/vo/DashboardStatsVo.java`
3. `frontend/src/views/dashboard/DashboardView.vue`

3. `v3Overview` 已包含：
   - totalPlans
   - draftPlans
   - appliedPlans
   - abandonedPlans
   - bestPlan
   - appliedPlan
   - formalScheduleCount
   - totalUnassignedTasks
   - totalConflicts

### 4.2 阶段 3 开发判断

首页增强不需要推翻现有页面，应在现有 `DashboardStatsVo` 基础上补 V6 治理摘要字段。
