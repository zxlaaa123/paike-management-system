# V7 测试与验收清单

## 一、后端测试

### 1.1 方案展示字段

1. 有学期时 `semesterName` 正确。
2. 无学期时不抛异常。
3. 已知策略码能映射中文名。
4. 未知策略码保留原值或返回可读兜底。

### 1.2 教师连续节次

1. 同一天连续 3 大节返回 3。
2. 同一天第 1、3 大节不算连续。
3. 跨天不算连续。
4. 方案课表和正式课表都支持。

### 1.3 首页统计

1. 当前学期存在时返回统计。
2. 当前学期不存在时返回清晰错误或空状态。
3. 治理摘要查询失败不影响基础统计。

### 1.4 性能趋势

1. 趋势接口按时间排序。
2. limit 生效。
3. 慢操作标记符合阈值。

## 二、前端测试

1. `npx vue-tsc -b` 通过。
2. `npx vite build` 通过。
3. 方案列表展示学期名称和策略名称。
4. 统计页展示真实连续节次。
5. 首页展示新增统计卡片。
6. 性能基线页展示趋势和慢操作。

## 三、Playwright 验收

1. `npm run test:v6` 通过。
2. 方案列表页面 smoke 通过。
3. 统计页面 smoke 通过。
4. 首页 smoke 通过。

## 四、回归风险

1. 不改变 `SchedulePlanVo` 原字段名。
2. 不删除 `maxContinuousPeriods`。
3. 不改变现有分页结构。
4. 不改变认证接口。
5. 不引入破坏性数据库迁移。
